# Password Complexity Checker

A simple web-based tool that assesses the strength of a password based on various criteria.

## Features

- Real-time password strength assessment
- Visual strength meter
- Detailed criteria checklist
- Actionable feedback for password improvement
- Password visibility toggle

## Criteria Evaluated

- Password length (minimum 8 characters)
- Presence of uppercase letters
- Presence of lowercase letters
- Presence of numbers
- Presence of special characters
- Additional analysis for sequential and repeating patterns

## Strength Levels

- Very Weak: Easily crackable passwords
- Weak: Passwords that meet only a few criteria
- Medium: Passwords with moderate security
- Strong: Passwords that meet most security criteria
- Very Strong: Highly secure passwords that meet all criteria

## How to Use

1. Open `index.html` in any modern web browser
2. Enter a password in the input field
3. The strength meter and feedback will update in real-time as you type
4. Use the "Show" button to toggle password visibility

## Implementation Details

- Built with vanilla HTML, CSS, and JavaScript
- No external dependencies
- Client-side only (passwords are never sent to a server)
- Responsive design works on mobile and desktop
